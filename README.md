## 🧮 Python Calculator

This is a simple **menu-driven calculator** written in **Python** that can perform both **basic arithmetic** and **list-based operations**.

### ✨ Features
- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division (with zero-division check)  
- 🔼 Power (exponentiation)  
- ♻️ Modulus  
- 🧮 Floor Division  
- 📊 Average of multiple numbers  
- 🔺 Maximum and Minimum values  
- 🚪 Exit option  

### ⚙️ How It Works
- When you run the program, a menu appears with 11 options.  
- For operations **1–7**, the user inputs two numbers.  
- For operations **8–10**, the user enters a list of numbers separated by spaces.  
- The calculator handles invalid or empty inputs safely using error checks.  
- Enter **11** to exit the calculator.
